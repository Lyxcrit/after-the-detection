# Analyst Hunt Guide

1. Start with the anomalous successful sign-in.
2. Build the user's preceding 60-minute identity timeline.
3. Compare source IP, device state, application, authentication method, and session ID.
4. Use VPN and device inventory data to eliminate expected source changes.
5. Review the follow-on SharePoint activity in the same session context.
6. Separate help-desk and responder activity.
7. Decide what to revoke, what to reset, and which claims still need evidence.

# Analyst Hunt Guide

1. Validate what the starting PowerShell event proves.
2. Follow process and file pivots on `ADMIN-WS-07`.
3. Separate failed movement from successful compromise.
4. Explain legitimate deployment activity on the app servers.
5. Build the reset/isolation timeline.
6. Correlate post-reset auth, process, and file activity on `FILE-02`.
7. Separate backup and responder activity.
8. Decide when to preserve volatile evidence versus isolate.
9. Document evidence gaps, especially initial access to `FILE-02` and possible exfiltration.

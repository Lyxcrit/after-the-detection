# Data Dictionary

Eight CSV lookups are included, each with exactly 500 records:

- `detection_results.csv`
- `endpoint_service.csv`
- `endpoint_process.csv`
- `endpoint_file.csv`
- `software_trust.csv`
- `network_activity.csv`
- `change_records.csv`
- `response_activity.csv`

All timestamps are UTC ISO 8601.

# Data Dictionary

Nine platform-portable CSV lookups are included, each with exactly 1,800 records:

- `asset_inventory.csv`
- `change_records.csv`
- `detection_results.csv`
- `endpoint_file.csv`
- `endpoint_process.csv`
- `network_activity.csv`
- `response_activity.csv`
- `scheduled_task.csv`
- `software_trust.csv`

All event timestamps are UTC ISO 8601.
